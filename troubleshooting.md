# GitHub Troubleshooting

## Common Problems

### I can't create a repository

Make sure you are signed in to GitHub and have permission to create repositories.

### My changes are not appearing

Check that you committed your changes to the correct branch.

### I made a mistake

Don't panic. GitHub keeps a history of changes, so you can review previous versions of your files.

## Getting Help

If you cannot solve a problem, check the project's documentation or ask the community for help.
